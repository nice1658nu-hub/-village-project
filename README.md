# SmartVillage

โปรเจกต์นี้ถูก scaffold ให้รันด้วย Vite + React + Tailwind CSS โดยใช้ UI หลักจากไฟล์ `code.jsx`

## ติดตั้ง

```bash
npm install
```

## รันในเครื่อง

```bash
npm run dev
```

จากนั้นเปิด URL ที่ Vite แสดงใน terminal

## Build สำหรับ production

```bash
npm run build
npm run preview
```

## โครงสร้างหลัก

- `code.jsx` ไฟล์ component เดิมของระบบ
- `src/App.jsx` re-export มาที่ `code.jsx`
- `src/main.jsx` จุดเริ่มต้นของ React app
- `src/index.css` Tailwind และ custom animation/classes
