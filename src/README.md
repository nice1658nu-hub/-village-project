# Frontend (`src`)

- `app/` — จุดควบคุมสถานะ การเลือกหน้า และฟังก์ชันกลางของแอป
- `config/` — ชื่อระบบและค่ากลาง
- `data/` — ข้อมูลจำลองสำหรับโหมดเดโม่
- `features/` — หน้าจอแยกตามผู้ใช้และงาน เช่น ประชาชน หมู่บ้าน อบต. แผนที่ และรายงาน
- `layout/` — Sidebar และ Topbar ที่ใช้ร่วมกัน
- `services/` — การเชื่อมต่อ Laravel API และ Firebase
- `shared/` — คอมโพเนนต์ที่ใช้ซ้ำได้หลายหน้า
- `styles/` — CSS ของทั้งเว็บไซต์
- `utils/` — สูตรคำนวณและฟังก์ชันช่วย
- `App.jsx` — เชื่อมตัวแอปหลักเข้ากับ Vite
- `main.jsx` — เริ่มต้น React และผูกกับ HTML

ดูแผนที่ไฟล์ฉบับเต็มที่ `docs/PROJECT-STRUCTURE.md`
