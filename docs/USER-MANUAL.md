# คู่มือใช้งาน SmartVillage

## การเปิดระบบสำหรับสาธิต

ดับเบิลคลิก `START-SMART-VILLAGE.cmd` ที่โฟลเดอร์โครงการ รอประมาณ 5–10 วินาที ระบบจะเปิด `http://127.0.0.1:5173` อัตโนมัติ

## ลูกบ้าน

1. กดสมัครสมาชิก กรอกชื่อ เบอร์โทร อีเมลกู้คืน บ้านเลขที่ และรหัสผ่าน
2. รอผู้ดูแลอนุมัติ แล้วเข้าสู่ระบบด้วยเบอร์โทรศัพท์
3. เลือก “แจ้งเหตุ / ร้องเรียน” กรอกรายละเอียด เลือกหมวดหมู่และตำแหน่งบนแผนที่
4. เลือก “ใช้ตำแหน่งปัจจุบัน” ได้เมื่ออยู่จุดเกิดเหตุและอนุญาตสิทธิ์ตำแหน่ง
5. แนบรูป (ถ้ามี) แล้วส่งรายการ
6. ติดตามสถานะและดูรูปปิดงานในหน้า “ติดตามสถานะ”
7. กดชื่อมุมขวาบนเพื่อแก้อีเมลกู้คืนหรือเปลี่ยนรหัสผ่าน

## เจ้าหน้าที่

1. เข้าสู่ระบบและเปิดหน้า “งานที่ได้รับมอบหมาย”
2. เปิดรายละเอียด ตรวจพิกัดและรูปแจ้งเหตุ
3. เริ่มดำเนินการและเพิ่มบันทึก/รูปความคืบหน้า
4. เมื่อเสร็จ ให้แนบรูปหลังดำเนินการและส่งตรวจ
5. หากผู้ดูแลขอแก้ไข ให้ทำตามหมายเหตุแล้วส่งตรวจอีกครั้ง

## ผู้ดูแลระบบ

1. อนุมัติหรือปฏิเสธบัญชีที่รออนุมัติในหน้าจัดการคน
2. ตรวจรายการแจ้งเหตุ ใช้ช่องค้นหา ตัวกรองหมวดหมู่ สถานะ และช่วงวันที่
3. เปิดรายละเอียด ตั้งความสำคัญ และมอบหมายเจ้าหน้าที่
4. ตรวจผลงานที่ส่งมา เลือกรับรองปิดงานหรือส่งกลับแก้ไข
5. สร้าง/แก้ไขข่าวและแนบรูปภาพ
6. ดู Dashboard และดาวน์โหลดรายงาน PDF/Excel

## กู้รหัสผ่าน

กด “ลืมรหัสผ่าน” ที่หน้าเข้าสู่ระบบ กรอกอีเมลกู้คืน เปิดลิงก์ในอีเมล และกำหนดรหัสผ่านใหม่ ลิงก์มีอายุจำกัด หากไม่พบอีเมลให้ตรวจ Spam และตรวจว่า Gmail SMTP ถูกตั้งค่าแล้ว
