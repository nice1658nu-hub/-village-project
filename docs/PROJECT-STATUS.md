# สถานะระบบรับเรื่องร้องทุกข์ อบต.มะต้อง

## เปิดระบบแบบง่าย

ดับเบิลคลิก `START-SMART-VILLAGE.cmd` ระบบจะเปิด MySQL, Laravel Backend, React Frontend และหน้าเว็บให้อัตโนมัติ

## ระบบที่ใช้งานได้แล้ว

- สมัครและเข้าสู่ระบบด้วยเบอร์โทรศัพท์
- เจ้าหน้าที่ อบต. อนุมัติหรือระงับบัญชีประชาชน
- รองรับประชาชน ผู้ประสานงานหมู่บ้าน และเจ้าหน้าที่ อบต.
- ทะเบียนหมู่บ้านในเขต อบต.มะต้อง 12 หมู่ และแยกข้อมูลด้วยเลขหมู่
- แจ้งเหตุพร้อมรูปภาพ ตำแหน่ง GPS และแผนที่จริง
- ผู้ประสานงานเห็นและรับเรื่องเฉพาะหมู่บ้านของตน อัปเดตความคืบหน้า ส่งรูปจบงาน และส่งให้ อบต.ตรวจรับ
- ส่งต่อเรื่องที่เกินขีดความสามารถของหมู่บ้านให้ อบต.พิจารณา
- คำของบประมาณ วงเงินเสนอ วงเงินอนุมัติ ปีงบประมาณ แหล่งเงิน เลขเอกสาร และยอดใช้จริง
- เลขอ้างอิงเรื่องรูปแบบ MT-ปี-หมู่-ลำดับ
- Audit Log สำหรับการส่งต่อและการเปลี่ยนแปลงข้อมูลงบประมาณ
- ข่าวสารพร้อมรูปภาพ
- Dashboard และรายงาน PDF/CSV สำหรับเปิดด้วย Excel
- ค้นหา กรองหมวดหมู่ สถานะ ช่วงวันที่ และแบ่งหน้ารายการแจ้งเหตุ
- อีเมลกู้คืนและตั้งรหัสผ่านใหม่
- ผู้ใช้เปลี่ยนอีเมลกู้คืนและรหัสผ่านของตนเอง
- รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์
- Analytics อบต.: SLA แนวโน้ม ความเสี่ยง การคาดการณ์ และงบประมาณหลายสถานการณ์
- ค่าต้นทุนและเงินสำรองเก็บเป็นค่ากลางในฐานข้อมูล แก้ไขได้เฉพาะแอดมิน
- Firebase Web SDK และ Laravel Firebase Admin SDK พร้อมใช้งานเมื่อใส่ credentials

## ต้องตั้งค่าบัญชีภายนอกก่อนใช้งานจริง

1. Gmail SMTP หรือผู้ให้บริการส่งเมล เพื่อให้อีเมลกู้คืนเข้ากล่องจดหมายจริง ปัจจุบันโหมด local บันทึกเมลที่ `backend/storage/logs/laravel.log`
2. Firebase Cloud Messaging สำหรับ Push Notification จริง โค้ดรับ/ส่งและการเก็บ token พร้อมแล้ว แต่ยังไม่มี Web config, VAPID key และ Service Account ของโครงการ
3. Hosting และโดเมน HTTPS สำหรับเปิดใช้นอกเครื่อง localhost
4. Google Maps API หากต้องการเปลี่ยนจาก OpenStreetMap/Leaflet ที่ใช้ฟรีอยู่ในปัจจุบัน

## ก่อนสาธิตหรือส่งงาน

- เปลี่ยนรหัสผ่านเริ่มต้นของบัญชี อบต. และผู้ประสานงานหมู่บ้าน
- ใส่อีเมลกู้คืนจริงให้ทุกบัญชี
- สำรองฐานข้อมูล MySQL
- รัน `php artisan test` ในโฟลเดอร์ backend (ล่าสุดผ่าน 22 tests / 75 assertions เมื่อ 24 ก.ย. 2569)
- รัน `npm run build` ในโฟลเดอร์หลัก
